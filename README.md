# Minimum Viable Foundations (repo: sta)

Installable app (PWA) for tracking Stage 0 · Minimum Viable Foundations: sub-phases, phases, money milestones and stage exit criteria.
Everything is stored on the phone only.

- App: https://andregdj-rgb.github.io/sta/
- Install: open the link in Chrome on Android → ⋮ → Install app.
- Bring data across from the old console: Export / import data → copy, then in the app More → Data → Paste / copy backup text → Restore.
- Updating: change `VERSION` in `sw.js` with each release; the app shows "A new version is ready → Update".
